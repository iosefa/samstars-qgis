SAMStars for QGIS

Individual tree crowns from imagery and lidar rasters. Requires QGIS 4.0 or later. This experimental plugin uses the Processing Toolbox for analysis.

Setup · Segment · Train · Check dependencies

Set up the engine

  1. Open Plugins → SAMStars → Set up SAMStars.
  2. Select a Python 3.10–3.12 executable and click Install private engine. Python must have venv and ensurepip available.
  3. Alternatively, select an environment with samstars==0.2.0 and click Use existing. The environment is checked before selection.

Installation requires internet access and several GB of free space. The installer creates a private environment in the active profile under samstars/engines. QGIS and your base Python are unchanged. Failed installs leave the previous engine selected; successful repairs keep older engines. Keep the base Python installed.

Automatic installation supports Linux x64 (Ubuntu 20.04+) and Apple Silicon macOS 14+, following the SAMStars supported platforms. Other platforms need an existing environment and are untested. Linux uses CPU-only PyTorch. For CUDA or MPS, configure a compatible environment using the SAMStars installation guide. The environment variable SAMSTARS_PYTHON overrides the saved Python path.

Prepare the scene

Choose local GDAL-readable imagery, a single-band canopy height model in metres, and single-band first-return density. Imagery needs a projected CRS in metres, north-up orientation, and square pixels. Provide a defined CRS and matching coverage for all rasters. SAMStars aligns CHM and density to imagery; survey offsets still need correction beforehand. Density units and cell size must match training. Apply CHM/density scale and offset to pixel values first. Export web services and subdatasets as GeoTIFFs.

Segment tree crowns

In the Processing Toolbox, run SAMStars → Segment tree crowns. Select the three scene rasters and a trained model bundle directory containing manifest.json. Choose a new or empty output folder.

The final crowns/crowns.gpkg is loaded into the project and returned as CROWNS. Band choices come from the model. Advanced parameters allow overrides: RGB is a comma-separated list in red, green, blue order, with one-based indices. Blank RGB and zero NIR/texture reuse model settings; zero cannot disable a band stored in the model.

Train a model

Run SAMStars → Train a model. Select the three scene rasters, labeled crown polygons, and the SAM ViT-L checkpoint sam_vit_l_0b3195.pth from the official SAM checkpoint list. Use one valid polygon per tree and fully annotate the scene. Crop to the labeled area, because unlabeled pixels are treated as background.

Processing's selected-features option, layer subsets, and unsaved polygon edits are preserved in a temporary GeoPackage. RGB defaults to bands 1,2,3. Advanced parameters expose band choices and the SAM/StarDist epoch counts. The new model folder is returned as MODEL and OUTPUT; supply it to segmentation.

Storage and compute

CPU is the default. The device setting controls PyTorch proposals, and CPU mode hides CUDA from refinement. TensorFlow manages refinement acceleration independently; custom TensorFlow Metal environments can select their own devices. Start with a small area: large scenes and training can need substantial memory and time.

Outputs must be new or empty folders. Intermediate files are removed unless Keep intermediate files is checked. Choose a permanent output folder to retain results beyond the session. Cancel stops the worker and its child processes on Linux/macOS; partial output or temporary files can remain. Use a fresh folder for another run. Prepared tiles, resuming, and individual stages are available through the SAMStars Python API.

Check dependencies

Run Check SAMStars dependencies for an HTML report and Processing log. It checks scientific imports and small CPU operations, including compiled StarDist code, CRS transformation, and GeoPackage I/O. It does not download or validate a trained model and does not certify GPU availability. A failed check includes the underlying error; use setup to select or install a working environment.

For No module named venv or missing ensurepip, install your operating system's Python venv support or select a Python installation that provides it. A failed installation never replaces the selected engine.
